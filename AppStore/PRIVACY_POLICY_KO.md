# 고스트 런 개인정보 처리방침 초안

운영자·시행일·문의 이메일·공개 URL은 출시 전에 실제 정보로 입력해야 합니다.

## 위치 이용과 외부 지도 요청

현재 위치·속도·거리는 기기에서 계산해 게임 진행에 사용합니다.

- 건물 회피를 위해 현재 위치가 포함된 주변 지도 영역(약 1.3km 너비)을 건물 데이터 서버에 요청합니다. 중심은 격자로 둥글리며 전체 이동 경로나 정확한 위치 샘플을 쿼리로 보내지 않습니다. 요청 지역과 접속 IP는 상대 서버에 전달됩니다.
- Debug 개발용은 overpass-api.de를 사용합니다. Release에는 운영자가 선택한 별도 서버 주소가 필요합니다. 출시 전에 실제 서버 운영자, 목적, 로그/보관 기간 등 처리 내용을 이 문서에 반영해야 합니다.
- Safe Light 경로 요청의 출발지·목적지 좌표는 Apple 지도 서비스로 전달됩니다. Apple 지도에도 관련 정책이 적용됩니다.

모든 처리가 오프라인/기기 내에서만 이루어지는 앱은 아닙니다. 공개 개발 서버의 데이터 처리 방식은 해당 운영자의 정책을 확인해야 합니다.

## 기기 내 처리와 보관

앱이 관리하는 경로와 지도 데이터는 세션 메모리에서 이용하고 세션 종료 후 정리합니다. 지도 HTTP 세션은 디스크 캐시/쿠키를 사용하지 않습니다. 현재 개발자 계정/분석 서버로 이동 경로를 수집하는 기능은 없습니다.

최고 점수·최장 거리/시간·완료 횟수는 기기에 저장합니다. 결과 공유를 선택하면 점수·거리·시간 문구만 공유하며 좌표/경로를 넣지 않습니다. 번들 ID가 변경된 새 앱은 구버전 기록을 자동으로 읽거나 이전하지 않습니다.

백그라운드/잠금 시 위치 수집과 게임을 중단합니다. iOS 설정에서 위치 권한을 철회할 수 있습니다.
