# 고스트 런 App Store 문구 초안

## 이름 / 부제목

고스트 런 / 내가 직접 달리는 추격 생존 게임

앱 타이틀 GHOST RUN, Bundle ID com.hajaeyun.GhostRun. 이름의 사용 가능 여부와 상표는 아직 검토하지 않았습니다.

## 소개

유령이 나를 쫓아옵니다. 캐릭터가 아니라 내가 직접 움직여야 합니다.

10초 동안 주변을 확인하세요. GPS와 지도가 준비되면 추격이 시작됩니다. 유령은 빈 공간으로 접근하고 지도에 등록된 건물은 돌아갑니다. 실제로 달려 거리를 벌리고, Safe Light에 도달해 잠시 숨을 돌리세요. 위기에는 제한된 Ward로 추격을 멈출 수 있습니다.

- 실제 이동에 반응하는 생존 러닝
- 건물 회피 추격, 다크 지도와 큰 위험도 HUD
- 실제로 도달하는 회복 지점과 이동 보너스
- 3발의 비상 사격, 이동해서 얻는 탄약 보급
- 걷기와 달리기로 충전하는 파동, 추격과 숨 고르기 리듬
- 위험 햅틱과 선택형 음성
- 생존 시간·거리·기기 내 기록

정확한 위치와 인터넷이 필요합니다. 지도 누락, GPS 오차, 출입 제한, 다층 공간은 완벽히 판별하지 않습니다. 지도나 경로를 확인할 수 없으면 추격을 보류합니다. 현실의 안전을 우선하고 백그라운드/잠금 후에는 직접 재개하세요.

주변 지도 영역은 건물 데이터 서버로, 회복 지점 경로 좌표는 Apple로 전달됩니다. 지도 출처는 OpenStreetMap contributors(ODbL)입니다. 자세한 내용은 개인정보 안내를 확인하세요.

## 심사 메모와 제출 전 조치

로그인/광고는 없습니다. 보행 공간에서 실제 이동으로 플레이합니다. Debug 가상 이동/지도 시각화는 Release에서 제외합니다.

**현재 Release는 별도 건물 데이터 서버 설정 전 게임 시작이 보류됩니다.** 공개 개발 서버를 출시 백엔드로 사용하지 마세요. GhostObstacleEndpoint 설정, 실제 운영 서버의 개인정보 처리 검토, 지원/개인정보 URL, 스크린샷, 현장 검증 후 문구와 심사 메모를 확정해야 합니다.
